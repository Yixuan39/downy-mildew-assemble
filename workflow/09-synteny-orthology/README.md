# Stage 09 - Orthology and synteny

OrthoFinder over the staged proteomes produces the orthogroups that GENESPACE and the synteny
notebook use for the comparative genome analysis.

| file | purpose |
|---|---|
| `orthofinder-contigs.sh` | Run OrthoFinder over the proteomes staged for GENESPACE. |

Large outputs remain under `$HOME/project_data/downy/genespace-contigs/`; the manuscript figure is
committed under `figures/`.
