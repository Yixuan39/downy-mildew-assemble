# Telomeres

`tidk-telomere-long-contigs.sh` searches finalized nuclear contigs for TTTAGGG. `plot-tidk-telomeres.R` plots the profiles. Outputs are in `results/telomeres/`, with tables in `data/tidk_telomeres/` and manuscript exports `figures/Figure_S1.{pdf,png}`. The PDF retains the vector plot; the PNG is a 150-dpi preview of the tall supplementary figure.
